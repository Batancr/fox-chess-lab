# Fox Chess Lab

A chess analysis site that runs in your browser: **https://batancr.github.io/fox-chess-lab/**

This repository holds only the published copy of the site, which GitHub Pages serves, and the posts people share to
the site's **Community** tab (in `docs/community/`). The site's own code is shrunk for speed; its working source
isn't public.

## Community posts

Submit from the site: **Share**, then **Submit to Community**. That opens an issue here, and a GitHub Action checks
the post and adds it to `docs/community/`. To ask for a post to be taken down, open an issue.
